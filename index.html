DexLink: Synthesizing Dexterous Demonstrations from Chained Hand–Object Poses

DexLink synthesizes diverse dexterous behaviors from sparse, reusable hand–object interaction templates. Given key task waypoints, it retargets static interaction templates to target objects, links the retargeted poses into an approximate reference trajectory, and uses residual reinforcement learning to refine the reference into a closed-loop policy.
